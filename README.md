# Price Memory · The 11.11 Study

An interactive study of how the same checkout price can appear to be a different deal when its reference price changes.

## Try the prototype

Download the repository, then open `index.html` in a browser. Keep the two `headphones-*.png` images beside it. No installation is required. An [optional standalone copy](https://drive.google.com/file/d/1a4W_WcS76it41ZatnBs4IzKXbLiKBCcb/view) embeds the images and can be opened by itself.

Shopper view presents a fictional headphone offer. Reveal its price memory to compare the headline discount with savings against the usual $100 price. Merchant studio offers two dates, a price-increase control, a coupon strategy, and an editable response assumption.

## Model boundaries

The product and prices are fictional teaching values. Discount arithmetic follows the inputs; the purchase response is an adjustable hypothetical assumption. The chart shows modeled gross revenue, not profit. It does not establish real merchant intent or consumer behavior.

Implemented with HTML, CSS, and JavaScript, with English/Chinese controls and responsive layouts.
